# UndisputedWell — frontend

See the [repo root README](../README.md) for how to run, test, and deploy the whole stack, and
[PLAN.md](../PLAN.md) for the architecture decisions.

React + TypeScript + Vite, built with `npm run build`, tested with `npm run test:coverage`
(Jest + React Testing Library) and `npm run test:e2e` (Playwright, against the real stack).
